# Portfólio de Ícaro Ferreira

Site pessoal de analista de dados, em português e inglês.

- Português: https://icaroferreirafs.github.io/
- English: https://icaroferreirafs.github.io/en/

## Estrutura

```
index.html          página inicial (português)
service-*.html      páginas de serviço (português)
en/                 versão em inglês, com a mesma estrutura
assets/img/         foto, ícones e imagens de compartilhamento
assets/docs/        currículos em PDF (português e inglês)
```

## Tecnologias

- HTML e CSS puros, sem framework
- JavaScript simples (menu ativo e texto digitando)
- Fontes Raleway, Roboto e Poppins (Google Fonts)
- Formulário de contato via Formspree
- Hospedagem no GitHub Pages

## Como editar

- Cores: no começo do `<style>` do `index.html`, na linha `:root`
- Textos: direto nos arquivos `.html`. Atualize as duas versões (raiz e `en/`)
- Publicar: commit e push na branch `main`. O GitHub Pages atualiza em 1 a 2 minutos
